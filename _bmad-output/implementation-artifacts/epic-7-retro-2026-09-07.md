## 4. Patterns Found & Areas to Improve

### Pattern 1: Event Loop Scoping with Async Locks in Python 3.10+
- `asyncio.Lock()` created at module load time raised `RuntimeError: There is no current event loop in thread`.
- **Fix:** Instantiate locks inside coroutines/getters or bound to the active loop.

### Pattern 2: State Synchronization Between UI & Worker Loop
- Terminating Telethon session disconnects the client; worker loop dropped events as designed, but UI status polling requires invalidating both `telegramAuth` and `health` query keys.
