## 4. Team Discussion — What to Improve

### Process Issue: Unanchored Action Items

**Root cause:** Two Epic 4 commitments (items 2 and 5) had no story file, no sprint-status entry, and no owner assignment. They became invisible between epics.

**Fix:** Every retro action item must be attached to a story or added as a named pre-epic prep task in `sprint-status.yaml`. No floating commitments.

### Code Review Patterns to Watch in Epic 6

| Pattern | Seen in Epic 5 | Risk in Epic 6 |
|---|---|---|
| Memory leaks in subscriber sets | SSE broadcaster (5-2, patched in 5-3) | React `EventSource` — ensure `useEffect` cleanup |
| Module-level instantiation side effects | `main.py` settings at import time (5-2) | React context providers — avoid side effects in module scope |
| Fire-and-forget async tasks | `admin.py` reconnect (5-3) | Any `useEffect` that spawns async work |
| Duplicate event emission | SSE stream replay race (5-3) | Real-time log deduplication in the UI |
