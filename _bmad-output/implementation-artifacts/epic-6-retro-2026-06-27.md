## 4. Patterns Found & Areas to Improve

### Pattern 1: Tailwind v4 Color Utility Naming — 3 of 6 stories

The `text-color-active` vs. `text-active` naming trap appeared in Stories 6.1, 6.3, and 6.4. It was documented in Story 6.1 Dev Notes and carried into subsequent stories. Yet it kept surfacing as a code review finding.

**Root cause:** Tailwind v4 strips the `color-` prefix from CSS variable names when generating utility classes. This is unintuitive. Without a lint gate, every new agent starts with fresh risk of repeating this mistake.

**Fix required:** Structural — a GOTCHAS.md file or ESLint custom rule.

### Pattern 2: useEffect Cleanup / Memory Leaks

Appeared in Stories 6.1 and 6.6. Both caught in review. The Epic 5 warning transferred correctly — the review layer is catching it.

### Pattern 3: Deferred UX Gaps

Five deferred items across the epic. Most are cosmetic. One stands out:
- `handleSelectAll` only selects current page items [ForwardsList.tsx] — genuine UX gap for users with more than 50 rules.
